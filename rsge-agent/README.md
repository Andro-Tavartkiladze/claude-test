## გაშვება

```bash
pip install -r requirements.txt
playwright install chromium

python login.py           # ხილული ბრაუზერი — ლოგინი ხელით
python login.py --check   # შენახული სესია ცოცხალია თუ არა
```

## პაროლის შესახებ

პაროლი **არსად არ ინახება** — არც კოდში, არც `.env`-ში, არც სესიის ისტორიაში.
სკრიპტი ხსნის ხილულ ბრაუზერს და ელოდება, სანამ ლოგინს, SMS კოდს და
პროფილის არჩევას ხელით გააკეთებ. შემდეგ ინახავს მხოლოდ session cookie-ებს
`storage_state.json`-ში, რომ შემდეგი გაშვებები ავტომატური იყოს.

`storage_state.json` **არ უნდა მოხვდეს git-ში** — იგი ცოცხალი სესიაა.

## ნაბიჯი 1-ის შემდეგ

`login.py` ბოლოს ბეჭდავს მთავარ გვერდზე არსებულ ბმულებს და `shots/`-ში
ტოვებს screenshot-ებს. ეს ორივე გამომიგზავნე — მათი მიხედვით ავაწყობ
ნავიგაციას ზედნადების ფორმამდე.

## რატომ Playwright და არა SOAP

დროებით. RS.ge-ს აქვს ოფიციალური ვებ-სერვისი
(`services.rs.ge/WayBillService/WayBillService.asmx`), სადაც ზედნადები
`save_waybill`-ით იქმნება — UI-ს ცვლილებებზე დამოკიდებულების გარეშე.
როგორც კი სატესტო სერვისის მომხმარებელი (`su`/`sp`) გექნება, ამ სკრიპტს
SOAP კლიენტით ჩავანაცვლებთ. Playwright დარჩება მხოლოდ იმაზე, რასაც
ვებ-სერვისი არ ფარავს.
